# Website assets

这里只放你自己提供或确认使用的图片、GIF 和视频封面。

建议文件名：

- `hero.gif`：首页全屏主视觉
- `portrait.jpg`：Legacy 区域竖版图片
- `moment-01.gif`：Gallery 01
- `moment-02.gif`：Gallery 02
- `moment-03.gif`：Gallery 03
- `moment-04.gif`：Gallery 04

YouTube 视频不需要上传到此目录。只需在 `index.html` 中找到 `VIDEO_ID`，替换为视频地址中的 ID，并按照注释启用 iframe。
