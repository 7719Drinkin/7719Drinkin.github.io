# Music media hierarchy

Music assets are organized by content type and artist.

```text
assets/Music/
└── Artists/
    ├── ZhangYusheng/
    │   ├── hero/
    │   ├── portraits/
    │   ├── albums/
    │   └── gallery/
    └── TanYonglin/
        ├── hero/
        ├── portraits/
        ├── albums/
        └── gallery/
```

Each artist is registered in `data/music/artists.json` and has a matching detail file in `data/music/artists/`.
